# Тихий ридер для Android

Личный ридер на русском языке. Принимает ссылку на книгу с loveread.ec, последовательно загружает её страницы и сохраняет текст на телефоне.

## Скачать APK

1. Откройте [Actions → Build Android APK](https://github.com/StevenRis/android-reader/actions/workflows/build-apk.yml).
2. Откройте последнюю успешную сборку **Test and build APK**.
3. Внизу страницы в **Artifacts** скачайте **QuietReader-APK**. Для скачивания нужно войти в GitHub.
4. Распакуйте ZIP и откройте **app-debug.apk** на телефоне.
5. Если Android попросит, разрешите установку из используемого браузера или файлового менеджера.

Поддерживается Android 8.0 и новее. Это подписанная debug-сборка для личного использования, не публикация в Google Play. Ключ для обновлений хранится в кэше Actions; если кэш удалён, для установки новой сборки может потребоваться удаление предыдущей версии с потерей локальных книг.

## Как читать

- Вставьте ссылку вида `https://loveread.ec/read_book.php?id=8466&p=1` и нажмите **Скачать книгу**. Поддерживается также ссылка на карточку `view_global.php?id=…`.
- Держите приложение открытым во время загрузки. Страницы загружаются последовательно с паузами; большая книга может занять несколько минут.
- Загрузка сохраняется по страницам. После ошибки, остановки или закрытия приложения нажмите **Докачать**.
- **Читать** доступно и для частично скачанной книги. Недоступные страницы помечаются сообщением; завершённая книга читается без интернета.
- Стрелки переключают страницы сайта; внутри страницы текст прокручивается. Нажатие на номер страницы открывает переход к нужному номеру.
- **A− / A+** меняют шрифт, **Ночь / Свет** переключают тему. Место чтения и настройки сохраняются.
- Экран остаётся включённым во время чтения. Книги можно удалить из библиотеки.

## Данные

Тексты книг отсутствуют в репозитории, сборке и артефактах GitHub. Загрузка происходит непосредственно с телефона в закрытый каталог приложения. Нет аккаунтов, аналитики или передачи библиотеки на сервер. Удаление приложения удаляет книги и настройки.

## Ограничения

Парсер зависит от разметки сайта. Блокировки, CAPTCHA, недоступность сайта, ограничения провайдера и изменения HTML могут помешать загрузке. Приложение не обходит защиту доступа. Сетевые запросы используют HTTPS; при ошибке текст и прогресс уже скачанных страниц сохраняются.

Приложение не использует фоновую службу: Android может остановить загрузку после сворачивания. В этом случае вернитесь и нажмите **Докачать**.

## Сборка и проверка

Java 17, Gradle 8.9, Android Gradle Plugin 8.7.3, Android SDK / Build Tools 35. CI устанавливает инструменты автоматически; локально нужен установленный Gradle 8.9, wrapper в проекте не включён.

```sh
gradle testDebugUnitTest lintDebug assembleDebug
```

Модульные тесты проверяют допустимые ссылки, пагинацию, выделение текста и отказ от страниц блокировки. Дополнительная проверка сайта получает только первую страницу, проверяет контейнер текста и количество страниц, не сохраняет и не выводит текст книги. Доступность сайта из GitHub может отличаться от доступности на телефоне, поэтому этот сетевой шаг не блокирует выдачу APK.

```sh
LIVE_SITE_TEST=1 gradle testDebugUnitTest --tests com.stevenris.reader.LiveSiteTest --rerun-tasks
```

Отчёты доступны в артефакте **Verification-reports**.
