# Мой гараж

Android-приложение для нескольких автомобилей, обслуживания и заправок. В версии 1.3 главный экран выполнен в тёмном стиле «Приборная панель»: пробег, круговой ресурс ближайшей замены, просроченные работы и расход топлива.

Для автомобиля укажите текущий пробег. Для расходника задайте название, интервал, пробег и дату замены. Через «Добавить запись» можно внести заправку или замену. Через карточку расходника доступны история, исправление даты и пробега, а также добавление прошлой замены. Расход топлива считается между полными баками с учётом промежуточных заправок.

Данные хранятся локально в SQLite. Сохраните JSON-копию перед удалением старой версии. Подпись сборок пока меняется: если новая версия не устанавливается поверх старой, экспортируйте копию из установленного приложения, удалите старую версию, установите новую и восстановите JSON. Импорт заменяет текущие данные.
