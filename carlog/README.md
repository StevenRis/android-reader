# Мой гараж

Локальное Android-приложение для учёта обслуживания и заправок нескольких машин.

Для машины укажите текущий пробег. Для расходника задайте название, интервал, пробег и дату замены. При достижении интервала приложение покажет, что пора менять; если интервал превышен, покажет просрочку в километрах.

Через «Изменить / история» можно добавить старую замену. В списке истории нажмите на запись, чтобы исправить дату и пробег либо удалить ошибочную запись (кроме единственной записи расходника). Последняя по пробегу замена автоматически определяет ресурс расходника.

При заправке обновляются пробег и ресурс. Расход топлива считается от полного бака до полного бака, включая промежуточные заправки.

Данные хранятся на телефоне в SQLite. Сохраните резервную копию в JSON перед удалением старой версии: подпись каждой сборки пока меняется, поэтому APK может не устанавливаться поверх прошлой версии. Импорт полностью заменяет текущие данные.
