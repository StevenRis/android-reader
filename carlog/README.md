# Мой гараж

Локальное Android-приложение для учёта обслуживания и заправок нескольких машин.

Добавьте машину с текущим пробегом; затем добавьте расходник с пробегом последней замены и интервалом. После каждой заправки обновляется пробег и ресурс в процентах. Расход топлива считается от одной заправки до полного бака до следующей, включая промежуточные неполные заправки. До первой пары полных заправок расход не рассчитывается.

Данные находятся на устройстве в SQLite. Экспортируйте резервную копию из меню приложения; при импорте она полностью заменяет текущую базу. Для обновлений используйте APK, собранный из той же ветки с сохранённым ключом подписи.
