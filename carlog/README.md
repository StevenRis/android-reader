# Мой гараж

Локальное Android-приложение для учёта обслуживания и заправок нескольких машин.

Для машины укажите текущий пробег. Для расходника укажите название, интервал, пробег и дату последней замены. Можно добавить запись с меньшим пробегом, чем сейчас на одометре, и через «Изменить / история» внести другие прошлые замены. История не меняет текущий пробег машины и не сбрасывает отсчёт от последней по пробегу замены.

При заправке обновляются текущий пробег и оставшийся ресурс всех расходников. Расход топлива считается от полного бака до полного бака с учётом промежуточных заправок.

Данные хранятся на телефоне в SQLite. Используйте «Сохранить резервную копию», чтобы выгрузить JSON. Импорт полностью заменяет содержимое приложения. Если подпись следующей сборки отличается и Android не даёт установить обновление поверх старой версии, сначала сделайте копию, затем удалите приложение, установите новое и восстановите данные из копии.
